Project Introduction

SuperMart Queue Simulator is a web-based project designed to manage customer queues at supermarket checkout counters.

Project Objectives

  • To manage customer queues efficiently.
  • To reduce customer waiting time.
  • To implement Priority and FIFO scheduling.
  • To distribute customers among available counters.
  • To monitor checkout counter status.

Technologies Used
