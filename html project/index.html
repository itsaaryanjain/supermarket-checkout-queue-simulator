How the Simulator Works

  1. Enter the customer's name and number of items.
  2. Select the priority option if required.
  3. Click Start / Assign Customers to send customers to free counters.
  4. Click Complete Next Bill when billing is finished.
  5. The next customer in the queue moves to the free counter.
